# Webhook Contracts: Real-Time Tracking System

*No external webhooks are defined for this feature. External map provider integration is deferred to future implementation.*

## Future Webhook Points (Reserved)

The following webhook contracts are reserved for future map provider integration:

- `POST /webhooks/tracking/distance-calculated` — Receive calculated distance from map provider
- `POST /webhooks/tracking/eta-calculated` — Receive estimated arrival time from map provider
- `POST /webhooks/tracking/geofence-event` — Receive geofence enter/exit events from map provider
